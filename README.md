## 💡 Бүтээлч санаа

Портфолиог энгийн вэб хуудас биш, **90-ээд оны компьютерийн үйлдлийн систем** болгосон.
Зочин компьютер асаахаас эхэлж, desktop дээрх апп-уудыг нээж миний тухай мэдээллийг өөрөө судална.

1. **Ачааллын дэлгэц:** хар дэлгэц дээр "ширээ … сандал … компьютер … кофе ☕ … (2/2)" гэж өрөөний эд зүйлс нэг нэгээр ачаалагдана. Дарахад (эсвэл Enter) 3D өрөө нээгдэнэ.
2. **3D өрөө (Three.js):** миний ширээ — ретро компьютер, гар, хулгана, дэнлүү, ургамал, ном, уураа савсуулсан кофе, шагай, монитор дээрх наалт цаас; ханан дээр SparkDay-ийн зурагт хуудас, тавиур дээр жижиг гэр, цонхны цаана Богд уул ба Улаанбаатарын гэрэл. Хулганы дагуу камер бага зэрэг хөдөлнө. Хаана ч дарахад камер компьютерийн дэлгэц рүү ойртож, дэлгэц дотор desktop асна. Ширээн дээрх шагай дээр дарвал шууд «Шагай» тоглоом нээгдэнэ. Шөнө/өдөр горимоос хамаарч өрөөний гэрэл, цонхны тэнгэр солигдоно. Бүх эд зүйлийг энгийн дүрсүүдээр (box, cylinder, sphere) кодоор бүтээсэн — гадны 3D загвар ашиглаагүй.
3. **Ретро desktop:**
   - **Цонх:** гарчгаас нь чирж зөөнө, ▾ нуух, ▴ томруулах (эсвэл гарчиг дээр давхар дарах), ✕ хаах, баруун доод булангаас томруулна. Сүүлд дарсан цонх урд гарна.
   - **Дээд мөр:** идэвхтэй цонхны нэр, ⏻ (өрөө рүү буцах), дуу, ☾/☀ горим, **MN / EN** хэл солих, цаг.
   - **Баруун талын icon-ууд ба доод dock:** нээлттэй апп-ын доор жижиг цэг гарна.
4. **Апп-ууд:**
   - Миний тухай: нэр, чиглэл, нэг өгүүлбэр, намтар, замнал
   - Бүтээлүүд: хавтас бүр нэг бүтээл, дарахад тусдаа цонхонд зураг, тайлбар, холбоос
   - Ур чадвар: хэрэгсэл бүрийг аль бүтээлд ашигласан, хэлний түвшин
   - Холбоо барих: имэйл апп маягийн форм, бусад холбоос
   - readme.txt: сайтыг хэрхэн ашиглах заавар, CV

Бусад онцлог:
- **Шөнө / өдөр горим** (дээд мөрний ☾ / ☀ товч)
- **Easter egg — «Шагай» апп:** гар дээрээ `shagai` гэж бичих эсвэл лого дээр давхар дарахад нуугдмал апп нээгдэнэ. Монгол уламжлалт шагай орхих тоглоом бөгөөд хонь, ямаа илүү олон, морь, тэмээ ховор буудаг (бодит шагайтай адил магадлалтай). Дөрвүүлээ ижил буувал тусгай мессеж гарна. readme.txt-д сэжүүр бий.

Мөн: хоёр хэлтэй (монгол/англи), Web Audio API-гаар үүсгэсэн дуу, компьютер асах анимэйшн, бүх icon болон бүтээлийн зургийг SVG-ээр өөрөө зурсан. Гар утсан дээр цонх дэлгэц дүүрэн нээгдэнэ.

Санаа авсан эх сурвалж: [Joey de Ruiter-ийн портфолио](https://joeyderuiter.me/). Хэв маягаас нь санаа авсан, код, зураг, текстийг нь ашиглаагүй.

## ⚙️ Гол кодын тайлбар

**Цонхны менежер (`useWindows.js`)**
Нээлттэй цонх бүрийг state массивт `{ id, app, x, y, w, h, z, min, max }` хэлбэрээр хадгална.
- `open(app)`: цонх аль хэдийн нээлттэй бол зөвхөн урд гаргана. Үгүй бол шинэ цонхыг өмнөхөөсөө бага зэрэг доош, баруун тийш байрлуулж нэмнэ.
- `focus(id)`: `z` утгыг хамгийн их болгож цонхыг урд гаргана (CSS `z-index`).
- **Идэвхтэй цонх** = нуугдаагүй цонхнуудаас `z` нь хамгийн их нь. Дээд мөрөнд түүний нэр гарна.

**Цонх чирэх (`Window.jsx`)**
1. `pointerdown`: хулганы байрлал ба цонхны зүүн дээд булангийн зөрүүг (`dx`, `dy`) хадгална, `setPointerCapture` хийнэ.
2. `pointermove`: шинэ байрлал = хулгана − зөрүү. Дэлгэцээс гаргахгүйн тулд `Math.min/max`-аар хязгаарлаад `move()`-оор state-д хадгална.
3. `pointerup`: чирэлтийг дуусгана.

**Хэл солих (`lang.jsx`)**: `TEXT.mn` ба `TEXT.en` объектод бүх текст байна. Context нь одоогийн хэлний объектыг `t` болгон өгөх тул компонентууд `t.apps.about` гэх мэтээр авна. Сонголтыг `localStorage`-д хадгална.

**3D өрөө ба камер (`room/Room.jsx`)**
- Эд зүйл бүр нь `<mesh>` — дүрс (`boxGeometry`, `cylinderGeometry` ...) ба материал (`meshStandardMaterial`)-аас бүрдэнэ. Байрлалыг метрээр өгсөн (ширээний гадаргуу y = 0.75).
- `useFrame` нь кадр бүрт (секундэд ~60 удаа) ажиллана. Камерын байрлалыг зорилтот цэг рүү `lerp`-ээр (шугаман интерполяц) бага багаар ойртуулна: эхлээд хулганы дагуу, дарсны дараа дэлгэцийн урд талын цэг рүү.
- Камер дэлгэцэд 3 см-ээс ойртмогц `onArrive()` дуудагдаж, `App` үе шатыг `"room"` → `"desktop"` болгоно.
- Дэлгэц болон цонхны тэнгэрийг `<canvas>` дээр зурж `CanvasTexture` болгосон.
- Three.js том сан тул `React.lazy`-гээр тусад нь ачаалж, ачааллын дэлгэцийн үеэр урьдчилан татна.

**Шагай (`apps/Shagai.jsx`)**: `randomSide()` нь 0–1 хооронд санамсаргүй тоо авч, тал бүрийн магадлалыг (хонь 0.38, ямаа 0.38, морь 0.12, тэмээ 0.12) дарааллаар нь хасна. Тоо 0-ээс бага болсон үеийн тал нь сонгогдоно (жигнэсэн санамсаргүй сонголт).

**Горим солих**: `<html data-theme="day">` болоход CSS хувьсагчид (`--desk`, `--bar`, `--dock` ...) өөрчлөгдөж бүх өнгө нэг дор солигдоно.
